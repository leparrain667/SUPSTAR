# Démonstration publique

La version publique de SUPSTAR est accessible ici :

<https://supstar-xi.vercel.app/login>

Le frontend est déployé sur Vercel. Le backend REST et PostgreSQL sont prévus pour Render via le fichier `render.yaml`.

Pour tester l'application :

1. Ouvrir le lien ci-dessus.
2. Créer un compte avec email/mot de passe ou Google si OAuth est configuré.
3. Créer une liste, ajouter un lieu, puis tester la carte, les filtres, les avis et l'import/export.
